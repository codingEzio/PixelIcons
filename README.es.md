exportación.

## Uso

Use `icons/<id>.svg` directamente; se incluye también `editable grids.json`.
catalog.json conserva ID y hashes estables. Para usar los archivos no necesita
servidor, cuenta o herramientas de compilación. Los SVG usan currentColor: sólo
al insertarlos inline heredan color CSS. Un img no hereda el color del texto. Se
conservan rejillas editables y tamaños de lienzo originales.
