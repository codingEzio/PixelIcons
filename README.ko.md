## 사용

`icons/<id>.svg`를 직접 사용하며 `editable grids.json`도 포함합니다.
catalog.json에 안정된ID와 원본／출력 해시가 있으며 사용에 서버、계정、빌드
도구가 필요하지 않습니다. SVG currentColor는 inline에서 CSS 색을 상속하며 img는
주변 글자색을 상속하지 않습니다. 편집 그리드와 원래 캔버스 크기를 유지합니다.

포함됩니다. Git 이력은 원본 비공개 저장소와 독립되어 있습니다. 비공개 원본과
선택되지 않은 브랜드 관련 아이콘 두 개는 포함하지 않습니다. 출처·메타데이터·시각
검토 범위는 제한적이며 포괄적인 권리 확인을 뜻하지 않습니다. LICENSE-SCOPE.json
및 public-files.json을 참조하세요.
